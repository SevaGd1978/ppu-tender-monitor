# Мониторинг тендеров: ППУ-изоляция трубопроводов

Дашборд виртуального отдела мониторинга тендеров по ППУ-изоляции (44-ФЗ / 223-ФЗ, РФ).

## Возможности

- Сводная статистика: число активных закупок, сумма НМЦК, ближайший дедлайн
- Таблица тендеров с фильтрами (поиск, тип заказчика, статус) и сортировкой
- Сводка по ролям отдела (поиск, анализ рынка, юрпроверка, требования к участию, статусы)
- Каталог источников мониторинга (ЕИС + 14 площадок)

## Стек

React + TypeScript + Vite + Tailwind CSS + shadcn/ui

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка в dist/
```

## Данные

Тендеры и источники описаны в `src/data/tenders.ts` (запуск №1 — 27.09.2026, 09:15 МСК).
Обновление — правкой этого файла при каждом запуске мониторинга.

## Деплой

Сайт публикуется на GitHub Pages через Actions (ветка `gh-pages`).
